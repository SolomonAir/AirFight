# AirFight
SOLOMONAIR: AIR FIGHT
Версия: 5.0
Разработчик: SolomonAir


ОПИСАНИЕ

Пошаговая тактическая стратегия в стиле «Штаб Второй Мировой». 
Уничтожьте промышленность врага или собейте все его бомбардировщики. 
Играйте против ИИ, используйте ПВО, Радар и Спецоперации. 
Стройте новые самолеты на Верфи и открывайте достижения.

КАК ЗАПУСТИТЬ

1. Распакуйте архив (если вы скачали ZIP).
2. Запустите файл "SolomonAirFight.exe" двойным кликом.
3. Наслаждайтесь игрой! Установка не требуется.


УПРАВЛЕНИЕ
----------
- Левая кнопка мыши: выбор клетки для выстрела или выбор своего самолета.
- Кнопка «ХОД»: завершить ход.
- Кнопка «ПВО»: активировать ПВО (1 раз за матч).
- Кнопка «РАДАР»: просканировать зону 3х3 (1 раз за матч).
- Кнопка «ВЕРФЬ»: построить новый самолет.
- Кнопка «ОПЕРАЦИИ»: использовать спецоперации.
- Клавиша «~»: открыть консоль разработчика.
